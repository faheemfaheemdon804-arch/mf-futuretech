# mffuturetech — SEO Services Website PRD

## 1. Overview aur goals

Yeh website ek SEO expert (10 SEO services aur 6 tarah ke backlinks) ki personal brand site hogi jo visitors ko leads aur direct orders mein convert karegi. Sirf portfolio nahi, balkay gigs, backlinks aur guest posts wala, client login ke saath ek mini-marketplace.

**Problem:** Fiverr jaise platforms 20% fee lete hain, unke rules par dependency hoti hai, aur client ka data apna nahi hota. Apni site se direct orders, repeat clients aur aap ki SEO skill ka live proof milta hai: jo banda khud Google par rank karta hai, client us par jaldi trust karta hai.

**Goals (pehle 6 months, suggested targets: aap apne hisaab se adjust karein):**

| Goal | Kaise measure hoga | Suggested target |
| --- | --- | --- |
| Inbound leads | Contact form + WhatsApp clicks + call bookings | 30 / mahina |
| Direct paid orders | Website checkout se orders | 10 / mahina |
| Organic traffic | Google Search Console clicks | 3,000 / mahina |
| Registered clients | Naye sign ups | 40 / mahina |
| Email list | Newsletter / lead magnet signups | 500 total |

**Non-goals (v1 mein nahi):** dusre sellers wala multi-vendor marketplace, mobile app, poori site ka Urdu version, free SEO tools, courses, admin panel aur client portal.

**Content rule:** Reference site sirf structure aur features ke liye hai. Text, case studies, certificates aur screenshots aap ke apne honge; copy karna duplicate content bhi hai aur trust ka nuqsan bhi.

## 12. Site ki apni SEO aur performance

SEO expert ki site khud SEO ka namoona honi chahiye: client sab se pehle aap ki site PageSpeed aur Google par check karega.

**Performance (Google ke "Good" Core Web Vitals thresholds):** LCP 2.5 sec se kam, INP 200 ms se kam, CLS 0.1 se kam; mobile PageSpeed score 90+ ka target. Images WebP/AVIF, lazy load, fonts self-hosted, minimum JavaScript, CDN.

**Technical SEO:**

- Server-side rendered / static HTML (gigs aur services ka content bhi crawlable ho).
- Har page ka unique title (60 chars tak), meta description (155 chars tak), ek H1, canonical tag.
- XML sitemap (pages, gigs, services, tools, blog alag-alag), robots.txt, clean URLs (lowercase, hyphen).
- Breadcrumbs, internal linking: service ↔ gig ↔ case study ↔ blog.
- 301 redirect manager, custom 404 page (reference ki contact page jaisi 404 nahi).
- Login, sign up, order form, thank-you aur search result pages par noindex.
- Open Graph + Twitter cards har page par.

**Schema (JSON-LD):**

| Page | Schema |
| --- | --- |
| Home / About | Person + ProfessionalService (sameAs: Fiverr, Upwork, LinkedIn, YouTube) |
| Service / Gig | Service + Offer (price) + BreadcrumbList |
| Blog post | Article / BlogPosting + author |
| FAQ blocks | FAQPage (rich result ab Google kam dikhata hai, lekin markup rakhein) |

Note: apni hi site par apne reviews ka AggregateRating Google star rich result ke liye eligible nahi hota, isliye us par bharosa na karein.

**E-E-A-T aur trust:** real photo aur naam, author box har blog par, real GSC screenshots dates ke saath, certificates ke verify links, contact details, aur Fiverr/Upwork profile ke links.

**Tracking:** Google Search Console, GA4 (events: WhatsApp click, form submit, order, sign up, login), Bing Webmaster Tools, Microsoft Clarity (heatmaps).

## 13. Design aur UX

Design ka maqsad trust aur speed hai: saaf layout, ek accent color, real photos aur numbers; fancy animations nahi.

- **Style:** sirf dark theme: black background, white text, lime green (#92e259) primary color; light mode toggle nahi hoga. Green sirf buttons, links, icons aur highlights par; bade blocks mein nahi.
- **Typography:** 1 font family (Inter / Plus Jakarta Sans), body 16–18px, headings bold.
- **Mobile-first:** zyada local business owners mobile se aate hain; har page par sticky bottom bar: WhatsApp + Order/Contact.
- **CTA hierarchy:** Primary "Get Free Audit" / "Order Now", secondary "WhatsApp", tertiary "See case studies". Har screen par ek hi primary button.
- **Trust elements:** rating badges, client logos, "No password needed: manager access only", money-back/revision policy, response time.
- **Floating WhatsApp button** + optional live chat (Tawk.to / Crisp).
- **Accessibility:** WCAG 2.1 AA: color contrast, alt text, keyboard navigation, form labels.
- **Branding assets jo aap ko chahiye:** logo, professional photo (2–3), brand colors, favicon, OG image template, gig cover templates (Canva/Figma).
